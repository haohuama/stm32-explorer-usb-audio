## 1. 结论先行：现有原理图资料包与项目前提冲突

提示词规定「开发板为老版正点原子探索者，CODEC 默认 WM8978，禁止使用 V3 的 ES8388、禁止 V3 的 P5 USB/CAN 跳线方案，老式 Micro USB」。

对用户提供的 `3，原理图.zip` 逐文件核验后，**该资料包属于「探索者 V3（新版）」，不是老版**：

| 证据 | 文件 / 位置 | 原文摘录 |
|---|---|---|
| E1 | `EXPLORER_V3.4.pdf` 第 1 页，图名 `AUDIO&ETHNET.SchDoc` | `GND-THERMAL 29 / U1 / ES8388`；同页 `I2S DAC&ADC`、`MCLK1 DVDD2 PVDD3 SCLK5 DSDIN6 LRCK7 ASDOUT8` |
| E2 | `EXPLORER_V3.5.pdf` 第 1 页 | 同样出现 `U1 ES8388`、`SPK+ 和 SPK- 连接开发板自带的喇叭`、`PHONE`、`LINE_IN`、功放 `U3 MD8002A` |
| E3 | 两个主原理图全篇关键词统计 | `WM8978` 命中 **0 次**；`ES8388` 命中 1 次/份；`USB SLAVE` 66 / 34 次 |
| E4 | `探索者V3 IO引脚分配表.xlsx` Sheet1 标题 | 「探索者**V3** IO资源分配表」；`PB8/PB9 → 24C02 & ST480MC & ES8388 的 SCL/SDA`；`PA11/PA12 → USB D-/D+ 与 CAN_RX/CAN_TX 经 P5 跳线选择`；`PA1/PC1… → 接 YT8512C` |
| E5 | `EXPLORER_V3.4.pdf` 第 4 页 USB 部分 | 出现 `USB TYPE-C`、`USB-B(Mini)`、`USB SLAVE` |
| E6 | 正点原子官方文档对照 | 探索者 **V3**（2023）第 55 章音乐播放器：外扩 HIFI CODEC 为 **ES8388**；老版（2014）第 48 章音乐播放器：`wm8978.c`、`PHONE 端子 / P1 喇叭`、`KEY0/KEY2 切歌、KEY_UP 暂停` |

**判定**：按提示词硬性规则 1「所有硬件依据老版探索者原理图 + 实物，拒绝 V3 硬件参数」，这份资料包**不能**作为本项目的引脚分配、I2C 地址、时钟配置和 CODEC 驱动依据。它目前只作为「版本比对证据」保留在 `资料/原理图/`。

> 特别注意：提示词要求「引脚与外设实例一律以老版探索者原理图与官方例程为准，不自行指定引脚号」。因此本阶段**不输出任何引脚号结论**——包括资料包里那组 I2S2 → PB12/PB13/PC2/PC3/PC6，那是 V3 的接法，老版是否一致必须以老版原理图/例程核对后再定。

## 2. 老版 / V3 版本对照（用于现场辨认）

| 辨认点 | 老版探索者（本项目目标） | 探索者 V3（现有资料包） |
|---|---|---|
| 音频 CODEC | **WM8978** | **ES8388** |
| USB Slave 口 | 老式 **Micro USB** | Type-C / USB-B(Mini) 并存 |
| USB / CAN 跳线 | 无 P5 方案（待实物核对） | **P5** 跳线在 USB D-/D+ 与 CAN 间选择 |
| 以太网 PHY | 老版方案（待实物核对） | YT8512C（RMII） |
| 音频功放 | 待老版原理图核对 | MD8002A（`SPK_IN`） |
| 资料盘例程名 | 实验43 音乐播放器 / 实验52 USB声卡(Slave) | 第55章 音乐播放器（ES8388） |

## 3. 人工操作清单（请逐项执行并回传结果）

> 全部为**只读观察 / 拍照**动作，除第 A6 项外不需要改动硬件状态。任何插拔、跳线改动请先确认。

| # | 动作 | 判定标准 | 若不符合 |
|---|---|---|---|
| **A1** | 找到板上音频 CODEC 芯片（通常在音频端子附近、方形小封装），**读丝印或拍照回传** | 丝印为 `WM8978` / `WM8978G` 等 → 主线成立 | 若为 `ES8388`：**立即停止主线**，按提示词输出「本项目按 WM8978 设计，ES8388 需另开分支」，等待你确认 |
| **A2** | 看 USB Slave 口形状 | 老式 Micro USB → 支持老版判断 | 若为 Type-C / 板上有 P5 跳线丝印 → 很可能是 V3，回传照片 |
| **A3** | 数一下板上绿色弹簧端子并看丝印 | 应有 `SPK`（输出，接喇叭）与 `LINE_IN` / `PHONE`（输入） | 播放只用 SPK；不要用 LINE-IN 接电脑 |
| **A4** | 确认两个 USB 口分工 | `USB_SLAVE` → 电脑下发 PCM；`CH340 / USB_232` → 下载 + 调试打印 | 两者接错是 Phase 4 最常见的「没数据」原因 |
| **A5** | 检查跳线帽状态并拍照（不要改动） | 老版应无 P5 USB/CAN 选择跳线 | 若有 P5 → 说明是 V3，回传并暂停 |
| **A6** | 接好 ST-LINK（SWD：SWDIO / SWCLK / GND）与喇叭 | 只连线，不要求上电验证 | 板子独立供电时不要接 3.3V |
| **A7** | 确认本机工具链 | Keil MDK 版本、CubeMX 版本、是否已装 STM32F4 HAL 固件包 | 缺失需先补装，Phase 2 才能生成工程 |
| **A8** | **补充老版探索者原理图**（当前资料包不可用） | 放进 `资料/原理图_老版/` | 拿不到则必须明确告知，后续所有引脚结论标为「待核对」，不得猜 |

## 6. 本阶段故障排查清单

| 现象 | 排查方向 |
|---|---|
| 找不到 CODEC 芯片 | 查板子丝印图 / 老版硬件参考手册；不要靠资料包 V3 原理图反推 |
| 丝印被散热片或贴纸遮住 | 拍局部高清照，或查随板资料清单；**不要**据此默认 WM8978 后直接写代码 |
| 板子与资料包对不上 | 以**实物**为准（提示词：「最终以实物芯片丝印为准」），并回传差异 |
| 只有 V3 资料包 | 从正点原子老版（2014）资料盘 A 盘 / openedv 老版例程帖获取；**不要**用 `zdyz_stm32f407_explorerV3.html` 那套（ES8388） |
| 拿到的是 ES8388 | 停止主线，另开分支或改提示词，二选一由用户确认 |
| 工具链版本未知 | 先补齐 A7；CubeMX 生成的工程结构会直接决定后续代码插入位置 |
