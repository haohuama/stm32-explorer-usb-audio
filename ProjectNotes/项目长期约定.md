# STM32项目 · 长期约定（2026-11-14 精简；细节见 docs/ 与 skills/stm32f407-explorer-audio）

## 项目 / 硬件
- 老版正点原子探索者 STM32F407ZGT6（丝印 Explorer STM32F4 V2.7，非 V3）；CODEC=WM8978（I2C 0x34 实测）。**拒一切 V3 参数**（ES8388/P5/YT8512C/Type-C）；引脚以老版原理图+官方例程+实测为准，V3 资料仅供比对；真 V2.7 原理图始终没拿到。
- 唯一音频链：电脑→USB_SLAVE(OTG_FS CDC 送 PCM 16bit/44.1k/立体声 = 176400 B/s)→MCU 环形缓冲→I2S2→WM8978→SPK 绿色端子→喇叭。**声音不从电脑扬声器出**；CH340 只下载/调试打印，CDC 只承载 PCM 禁打印；LINE-IN/PHONE、USB-HOST A 口、绿色端子都不传数字音频。USB/CAN 跳线帽须置 USB 侧（人工）。
- 实测引脚：I2S PB12=WS/PB13=CK/PC3=SD/PC6=MCK(AF5)，DMA1_Stream4/Ch0 CIRCULAR 不开 NVIC；I2C PB8=SCL/PB9=SDA；PLLI2SN=271/R=2→MCLK 11.2917MHz。WM8978 写帧 (reg<<1)|(val>>8)+val&0xFF，58 项寄存器镜像。
- 禁外设：以太网/RTC/ADC/DMA2D/USB Host/CAN/串口屏；SDIO 白名单曾解除但 **TF 卡方案已否**（用户无卡，tf_player.c/h 已删），三模式里模块2/蓝牙未实现。
- 坑：不定义 HAL_UART_MspInit、不调 usart_init；时钟用自包含 SystemClock_Config；LCD 驱动里的 printf("LCD ID") 必须删（半主机 HardFault）。

## 固件要点（工程 C:/stm32TEST）
- Phase 0~4 完成，CDC 链路已交付。USB_APP=usbd_conf/desc/cdc_if/usb_device；i2s_audio.c = 8KB 环形 + 4KB 双缓冲 + HalfCplt/Cplt refill；it.c 补 OTG_FS_IRQHandler、DMA1_Stream4_IRQHandler；main.c 顺序 I2S→WM8978→audio_stream_start→MX_USB_DEVICE_Init。
- 构建硬约束：usbd_conf.h **禁 #include usbd_core.h**（循环包含→173 Error）；uvprojx 必须含 stm32f4xx_hal_pcd.c + _pcd_ex.c；Heap_Size≥0x400；usbd_conf.h 定义 USBD_malloc/free 宏；删过 12 个重复 USBD_LL_* stub。
- 切曲主通道 = **CDC SET_LINE_CODING 波特率编码**：上位机 `ser.baudrate=100000+idx` → 设备 `case CDC_SET_LINE_CODING` 判 100000≤baud<100016 → lcd_ui_select_song(baud-100000) + audio_stream_reset_position()。兼容 DTR/RTS 两位（只 0..2，wValue=3 端口刚开默认态忽略）。序号 = plNN−1。
- LCD：FSMC 800×480 横屏，User/Hardware/LCD/lcd_ui.c；**左 1/3 封面+信息+三个触屏按钮，右 2/3 歌词**；时间轴 = audio_stream_consumed_bytes()/176400，不用 HAL_GetTick；歌词只解析当前曲目；长句在 parse_lrc 阶段插 LRC_BR 折行。中文点阵行优先、ASCII asc2_1608 逐列，绘制函数不能混用。
- 按键：KEY0=PE4 下一首 / KEY2=PE2 上一首 / KEY1=PE3 音量− / WK_UP=PA0 音量+；**PA0 高电平有效必须 PULLDOWN**（曾误配上拉导致音量顶到 63、两个音量键失灵），KEYx 低有效 PULLUP。播放/暂停只在触屏按钮（XPT2046：T_PEN=PB1/T_CS=PC13/T_MISO=PB2/T_MOSI=PF11/T_SCK=PB0），CDC 上行 'N'/'B'/'P'/'R'。**屏上切曲 ≠ 换声音**。

## 桌面播放器（C:/stm32TEST/DesktopPlayer）
- 桌面快捷方式 `STM32 音乐播放器.lnk`（pythonw 无黑框 + app.ico），`py DesktopPlayer/app.py --selftest` 自检。GUI 只做 ffmpeg 转码 + 推 PCM + 显示歌词/封面，声音从板子喇叭出。自动预置 Tools/plNN.wav 六首，默认不自动播放。
- **串口独占**（Windows）：桌面播放器 / host_cdc_sender.py / play.bat 不能同时运行；`PermissionError(13, 拒绝访问)` = 被旧推流进程（常见 `--auto --wait -f plNN.wav --keys` 常驻）占用。2026-11-14 已加「释放串口」按钮：WMI 找 PID → taskkill → 播放线程 1~2s 自动重连；设备标签变红提示占用。排查：串口调试助手/第二个 GUI/设备管理器感叹号/重插 USB_SLAVE。
- 倍速必须在 ffmpeg 做（atempo 保持音调 / asetrate 变调），出口恒 44.1k，发送速率恒 176400 B/s；非 1.0 倍速 LRC 时间戳先除以倍速（scale_lrc）。暂停 = 停发 PCM，环形排空自动静音。控制帧 'ATK'+type+len，波特率 200000 进控制模式。
