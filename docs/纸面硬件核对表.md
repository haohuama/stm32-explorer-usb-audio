### 1.1 WM8978 芯片级规格（S5，datasheet 有页码，非推测）

| 规格 | 值 | 页码 |
|---|---|---|
| 采样率支持 | 8 / 11.025 / 12 / 16 / 22.05 / 24 / 32 / **44.1** / 48 kHz | p1 |
| 主时钟 | 支持 12 / 13 / 19.2 MHz 等参考时钟，内置 PLL | p1 |
| 数字音频格式 | I2S、左对齐、右对齐、DSP mode A/B；MSB first；主/从模式 | p22 / p70 |
| 字长 | R4 的 `WL[6:5]`：`00`=16 bit、`01`=20、`10`=24、`11`=32 | p73 |
| I2S 格式位 | R4 的 `FMT[4:3]` 设为 `10` = I2S（飞利浦）模式 | S4 第 49 章 |
| 软复位 | 对 R0（地址 `0x00`）写任意值 | p83 / S4 |
| 控制接口 | **2-wire（I2C 类）或 3-wire（SPI 类）可选**，由 `CSB/GPIO1`、`SCLK`、`SDIN` 承担 | p5 / p17-18 |
| 供电 | 模拟 2.5~3.6 V；数字核 1.71~3.6 V；SPKVDD 5 V 时 1 W / 8 Ω BTL 喇叭 | p1 |
| 封装 | 5×5 mm，32-lead QFN | p1 |
| 芯片引脚（非板级 GPIO） | `MCLK`=11、`DACDAT`=10、`ADCDAT`=9、`SPKGND`=24、`LOUT2`=25、`ROUT2`=23 | p5 |

> 注意：以上是**芯片**引脚，不是 STM32 的 GPIO，不能据此配置 CubeMX。

### 1.2 一致性核算（纸面）

- **格式兼容**：项目要求 16 bit / 44.1 kHz / 立体声 / I2S，datasheet 明确支持 16 bit 字长、44.1 kHz 采样、I2S 模式与立体声 DAC → ✅ 芯片层面成立。
- **带宽核算**：44 100 × 16 × 2 = **1 411 200 bit/s ≈ 1.41 Mbps**，远低于 USB Full-Speed 12 Mbps 的理论值 → ✅ 纸面带宽充足。但 CDC 走 bulk 传输、无等时保证，必须用环形缓冲吸收主机发送抖动（这正是 Phase 4 保留最小自研的原因）。
- **喇叭驱动**：WM8978 内置 BTL 喇叭驱动（1 W / 8 Ω @5 V SPKVDD）→ 纸面上绿色 SPK 端子可直接接喇叭；但**老版是否另接功放、端子接线方式仍需原理图确认**。

**② 完整代码**
**本阶段无代码产出**。用户已要求暂停代码适配；H1（丝印）与 H2（原理图）未确认前，写 WM8978 寄存器初始化 / I2S DMA / USB 栈配置会直接违反提示词规则 11 与「不自行指定引脚号」。未生成 `.ioc`、未编译、未上传。

**③ 预期现象**
工作区新增本表与 `docs/许可证核查表.md`；README 状态更新。无出声、无枚举、无烧录、无上传等任何硬件/网络发布现象。

**④ 故障排查清单**

| 现象 | 排查方向 |

## 7. 增量（14:50，详见 `docs/纸面核对与许可证复查_增量.md`）

本轮从**老版官方第 48 章 / 第 57 章教程**取得大量纸面事实（明确对应老版探索者 + WM8978G，非 V3）：I2S2/SPI2、IIC `MODE=0` 地址 `0X1A`（只写）、PB12/PB13/PC2/PC3/PC6、DMA1 Stream4 Channel0 双缓冲、`MCLK=256×fs`、44.1 kHz 查表 `{271,2,6,0}` 实际 44.108073 kHz（+0.0183 %）、PHONE / P1(SPK) 端子、按键映射、P11 跳线连 PA11/D- 与 PA12/D+、老版 UAC 例程为 48 kHz 等时传输并用 100 组缓冲 FIFO。

**状态变化只到「教程有纸面记载」为止**：H1（丝印）、H2（V2.7 整板原理图）仍未确认，H3~H6 由「完全未知」升级为「有纸面候选、待 V2.7 原理图核对」。按用户指令，**不把教程引脚 / 地址写成项目配置，不自行指定引脚号**。

另记两条差异：老版 UAC 是 48 kHz 而本项目 CDC 主线是 44.1 kHz；44.1 kHz 存在 0.0183 % 固有频偏 → 环形缓冲 / 欠载策略不可省。
