## 2. 版本无关 · 可复用知识（可用于 V2.7/WM8978 主线）

### 2.1 工具链与调试串口
- 编译：Keil MDK + **HAL 库**；建 HAL 工程见第8章。
- 调试/下载：DAP 仿真器（免驱）。
- **调试打印串口**：串口1 `PA9/PA10` 接板载 **CH340C** USB 转串口（第3.4节、第55/64/65章硬件资源均确认）。→ 与本项目的「CH340 → USART1 只走调试日志」约定一致。

### 2.2 USB_OTG_FS 物理引脚（由芯片决定，版本无关）
- **USB_SLAVE 的 D-/D+ 固定在 `PA11`/`PA12`**（第64章 64.2、第65章 65.2 硬件资源均写 `USB_SLAVE接口(D-/D+连接在 PA11/PA12上)`）。
- 第64章确认：USB 仅 **FS 模式（不支持 HS）**，无需特殊驱动，OS 原生识别。
- 对主线而言：V2.7 用 F407ZGT6，OTG_FS 同样落在 PA11/PA12，**这条可直接沿用**。

### 2.3 USB CDC（虚拟串口 / VCP）参考 —— 对应「先 CDC」主线
- 第65章：VCP = 用 USB **CDC 类** 实现虚拟串口。官方例程路径 `STM32Cube_FW_F4_V1.26.0 → Projects → STM324xG_EVAL → Applications → USB_Device → CDC_Standalone`。
- 上位机无需专门 USB 程序，串口调试助手即可。
- 这与本项目「先 CDC，UAC 标准声卡为可选升级」顺序一致；也与之前在用户 `D:\4，程序源码\` 里看到的 `CDC_Standalone` 来源吻合。
- 注意：本项目 CDC 用来**承载 PCM 音频流**（非普通回显），需在标准 CDC 例程上改 `usbd_cdc_if.c` 的接收回调与环形缓冲；第65章给的是"收到什么回什么"的基线。

### 2.4 USB Audio（UAC）参考 —— 对应「可选升级」
- 第64章：官方例程 `USB_Device → Audio_Standalone`，**USB 同步传输（isochronous）** 传音频，支持静音等控制命令。
- 关键限制：**ST USB 库标准路径仅支持 `USBD_AUDIO_FREQ = 48000`**（代码注释原文："ST USB 库目前只支持这一个采样率, 设置其他采样率无法正常工作"，见 64.3.2 `usbd_conf.h`）。
- 工程基于第43章（音乐播放器）改造；CODEC 底层在 `stm32f407_audio.c`（ST 原版对应 CS43L22，V3 改为 ES8388）。
- **对主线启示**：若日后上 UAC，默认仍是 48 kHz；要 44.1 kHz CDC 主线需走自定义 CDC 而非 UAC 标准类。

### 2.5 CODEC 控制总线 = 软件 IIC（GPIO 模拟），**非硬件 I2C 外设**
- 第36章 IIC 实验明确：用 **普通 IO 口模拟 IIC 时序**（即 `myiic.c` 那套 `IIC_Start/IIC_Stop/IIC_Wait_Ack/IIC_Send_Byte`）。
- 第55章硬件资源：`IIC 接口和 24C02、ST480 磁力计等共用` → CODEC 挂在**共享软件 IIC 总线**上。
- 第55章软件设计：CODEC 硬件驱动放 `BSP/` 目录，播放 APP 放 `USER/`（ES8388 驱动 = `es8388.c/.h`）。
- **对主线启示**：WM8978 也走同样的软件 IIC 总线，仅设备地址不同（`0x1A` vs ES8388 `0x10`）；之前在 `myiic.c` 看到的 `iic_wait_ack()` 250 次超时正是这套。本项目的「I2C 只读探测判型法」(写 `0x34`/读 `0x35` vs ES8388 `0x20`/`0x21`) 与第36章时序完全兼容。

### 2.6 I2S 音频数据通路（结构可复用，引脚 V3 专属）
- I2S 用 **SPI2（即 I2S2）**，`ClockSource = I2S_CLOCK_PLL`，`MCLKOutput = ENABLE`。
- 数据格式用 `I2S_DATAFORMAT_16B`（PCM 16 bit），标准 Philips。
- 发送走 **DMA**（I2S2 TX DMA 请求），句柄 `I2S_HandleTypeDef` + `DMA_HandleTypeDef`。
- WAV/PCM 文件解析（第55章 55.1.1）完全版本无关、可直接移植：`ChunkRIFF` / `ChunkFMT` / `ChunkDATA` 结构体，fmt 块含 `AudioFormat`(0x01=PCM)、`NumOfChannels`、`SampleRate`、`BitsPerSample`；16 bit 立体声的字节序（L/R 低字节在前）也已给出表格。
- **对主线启示**：I2S2 + PLL + MCLK + DMA + WAV 解析这套"骨架"可在 V2.7 上复用；只有**引脚号和 CODEC 寄存器表**要换。
