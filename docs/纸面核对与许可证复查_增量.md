## 3. 老版官方教程的纸面核对（本轮最大增量）

来源：正点原子《STM32F4 开发指南》**第 48 章 音乐播放器实验**、**第 57 章 USB声卡(Slave)实验**（2014-12-09，openedv），明确对应**老版探索者 + WM8978G**，不是 V3/ES8388。

| 项 | 官方教程纸面记载 | 对本项目意义 |
|---|---|---|
| CODEC 型号 | **WM8978G**，最高 192 kHz / 24 bit，板载全双工 I2S | 与「原厂默认 WM8978」一致；**丝印仍待拍** |
| 控制接口 | 两线 `MODE=0`（IIC）或三线 `MODE=1`；本章用 IIC，**地址固定 `0X1A`**；IIC 只写不读；7 位寄存器 + 9 位数据 | 为 H4 提供纸面候选；不作项目配置 |
| I2S 实例 | **I2S2 / SPI2**，飞利浦标准、主机发送、CPOL 低、16 位扩展帧 | 为 H3 提供纸面候选 |
| I2S 引脚（教程代码） | PB12=LRCK、PB13=SCLK、PC3=DACDATA、PC6=MCK(AF5)、PC2=ADCDATA(AF6) | ⚠️ **仅纸面记载**，需 V2.7 原理图核对 |
| 复用冲突 | IIC 与 24C02/MPU6050 共用；I2S_MCLK 与 DCMI_D0 共用 → I2S 与 DCMI 不能同时用 | 解释为何白名单禁止摄像头/DCMI |
| DMA | I2S2 TX = **DMA1 Stream4 / Channel0**，双缓冲循环、16 位宽、传输完成中断填充 | 为 Phase 3/4 的 DMA 时序提供官方依据 |
| 时钟 | HSE 8 MHz；`MCLK = 256 × fs`；44.1 kHz 查表 `PLLI2SN=271, PLLI2SR=2, I2SDIV=6, ODD=0` → 实际 **44.108073 kHz，误差 0.0183 %** | 纸面证明 44.1 kHz 可配；但存在固有频偏 |
| WAV | 支持 16/24 位立体声，低字节在前；标准 WAV 与 CD 同为 44.1 kHz / 16 位 | 与项目 PCM 参数完全对齐 |
| 输出端子 | PHONE 插耳机；**P1（SPK）外接 1 W@8 Ω 喇叭** | 印证绿色 SPK 为模拟输出 |
| 按键（第48章） | KEY0 下一曲、KEY2 上一曲、KEY_UP 暂停/继续；DS0 运行指示 | 与项目按键需求可直接对照 |
| 按键（第57章） | KEY0 音量+、KEY2 音量-，默认 65，范围 0~100；DS1 指示 USB 连接 | LCD 显示音量/连接状态 |
| USB 声卡实现 | 移植 **ST `STM32_USB-Host-Device_Lib_V2.1.0` → `USB_Device_Examples/AUDIO`**；仅 FS、免驱、**同步（等时）传输**；采样率固定 **48 kHz**（`USBD_AUDIO_FREQ`） | 印证上一轮关于 `stm324xg_usb_audio_codec.c` 归属旧库的判断 |
| codec 适配点 | `stm324xg_usb_audio_codec.c` 原配 CS43L22，改成 WM8978 底层 | 提示词里那个文件名**确实存在于老版 UAC 路径**；但本项目主线是 CDC/HAL，适配点仍是 `usbd_audio_if.c` |
| 缓冲机制 | USB 48 kHz 与 IIS 实际 47.991 kHz 有速率差 → 用 **100 个缓冲数组的类 FIFO + I2S DMA 双缓冲**，混叠时跳帧；每包 `(FREQ×2×2)/1000` = 192 字节，共 19 200 字节 | **现成的环形/多缓冲思路依据**，支持「不自研整个缓冲体系、只做最小适配」 |
| 接口分工 | 「USB 数据线要插 **USB_SLAVE**，不是 USB_232；USB_HOST 不要插任何外设」 | 与用户回传、项目链路完全一致 |
| USB 跳线 | 第 57 章提示 **P11 跳线帽连接 PA11↔D-、PA12↔D+** | ⚠️ 与用户所述「USB/CAN 二选一跳线」是否同一组，待实物/原理图核对 |
| 工具链 | 老版例程 MDK5.1 + 固件库 **V1.4.0（StdPeriph）** | 只取寄存器序列 / 时序，不把 StdPeriph 结构搬进 HAL 工程 |
| 可行性佐证 | 论坛官方回复「去掉 SD 卡后利用 USB 传音频、WM8978 直接播放」→「**可以的**」 | 项目目标在老版硬件上成立 |

### 3.1 两个必须记录的差异

1. **采样率不同**：老版 UAC 例程固定 **48 kHz**（等时传输，免驱）；本项目主线 CDC 要求 **44.1 kHz / 16 bit / 立体声**。因此 UAC 例程只能作为「USB 音频流 + 缓冲」的结构参考，不能整包照搬。
2. **44.1 kHz 有固有频偏**：教程算得 44.108073 kHz（+0.0183 %）。CDC bulk 本身无等时保证，再叠加这个频偏，**环形缓冲 + 欠载/溢出策略是必需的**，不是可选优化。这进一步支持 Phase 4 保留最小自研缓冲的理由。
