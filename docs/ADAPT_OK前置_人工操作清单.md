## 2. 【P0】拍音频芯片丝印照片（决定生死）

这是整个项目最关键的物理证据。你说过「原厂默认 WM8978，但丝印尚未拍到，按提示词以实物为准」——所以**不能用「默认」代替照片**。

**拍哪里**

- 老版探索者的音频 CODEC 在板子音频区，靠近 **SPK 绿色弹簧端子 / PHONE 耳机口 / LINE_IN** 那一带。
- WM8978 是黑色方形小芯片，**32 脚 QFN 封装，约 5 mm × 5 mm**（大概指甲盖的 1/4），顶面有激光刻字。可能印 `WM8978`、`WM8978G`、`WM8978GEFL` 或 Cirrus Logic 的 logo；ES8388 会印 `ES8388` / `ES8388S` 等。
- 分不清哪颗是 CODEC：把音频区所有小芯片都拍一遍，我来帮你认。

**怎么拍清楚**

1. 手机开**微距模式 / 专业模式对焦**，镜头垂直对准芯片顶面。
2. 光线从**侧面斜打**（激光刻字在斜光下最清楚），避免正面闪光造成反光白斑。
3. 用干净软布轻拭芯片表面灰尘；**不要**用刀片或硬物刮。
4. 多拍 3–5 张：一张整体音频区、一张芯片特写、一张斜光特写。
5. 同时拍**整板正面照**（要能看清 `Explorer STM32F4 V2.7` 丝印、USB 口形状、跳线帽）。

**判断标准**

| 丝印读出 | 结论 | 我接下来做什么 |
|---|---|---|
| `WM8978` / `WM8978G` 等 | ✅ 主线成立 | 收到 ADAPT_OK 后按 C1–C5 换 CODEC |
| `ES8388` 等 | 🔴 主线停止 | 输出「本项目按 WM8978 设计，ES8388 需另开分支」，等你确认，**不改代码** |
| 看不清 / 磨损 | ⚠️ 继续拍 | 换斜光、加放大镜；实在读不出告诉我，我给替代核对办法（但不会靠猜） |

**完成标准**：至少 1 张能清楚读出丝印的照片 + 1 张整板照，直接发到对话里。
