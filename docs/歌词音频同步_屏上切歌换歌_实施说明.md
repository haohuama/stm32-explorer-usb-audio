# 歌词严格同步 / 屏上切歌就唱对应歌 —— 实施说明

日期：2026-11-14 13:1x　固件 `Output/atk_f407.hex`（0 Error 0 Warning，Flash ~827KB）

## 为什么要改

设备端歌词时间轴本来就是 **「收到的真实 PCM 字节数 / 176400」**，与声音同源，天然同步；
暂停时停止发送，时间轴也跟着冻结。但有两个场景会破坏它：

| 场景 | 问题 |
|---|---|
| 桌面软件 seek / 换倍速 | 从 `base_ms` 开始重新渲染一段新 PCM，设备时间轴却仍从 0 起算 → 歌词**提前** |
| 屏上按键/触屏切歌 | 只换了屏上的内置歌词和封面，**音频还是电脑正在送的那首** → 「切到哪首歌词却不唱哪首」 |

## 改动 1：T_POS —— 歌词时间轴基准帧

新增控制帧（沿用现有 `'A''T''K'` 协议）：

```
type 0x05 POS : 4 字节小端毫秒，设置设备歌词时间轴基准
```

- `i2s_audio.c` 新增 `audio_stream_set_position(ms)`，把 ms 换算成 PCM 字节写进 `s_pos_bytes`
- `cdc_ctrl.c` 新增 `case T_POS`
- 桌面软件 `core_device.push_track(..., pos_ms=...)` 在推完歌词后下发基准

**倍速要一起缩放**：设备按字节计时 = 墙钟时间，而下发到设备的 LRC 时间戳已经除以倍速
（`scale_lrc`），所以基准也必须是 `base_ms / speed`。否则非 1.0 倍速下又会偏。

**时序坑（已修）**：`select_slot()` 只是置了 UI 的 pending 标志，真正的清零发生在下一次
`lcd_ui_tick()`，会把刚下发的 T_POS 冲掉。`audio_stream_set_position()` 因此额外记一个
一次性基准 `s_start_ms`，`audio_stream_reset_position()` 遇到它时「回到基准」而不是清 0。

## 改动 2：'S'+idx —— 屏上切歌通知电脑换 WAV

设备 → 电脑的 CDC 上行命令从 1 字节扩到 2 字节：

```
'S' + 1 字节 idx(0 基)   屏上切到了第 idx 首，电脑跳到对应 WAV
'P' / 'R'                暂停 / 继续
'N' / 'B'                下一首 / 上一首
```

- `usbd_cdc_if.c` 新增 `CDC_Cmd_Send2(c, d)`（一次 IN 传输发 2 字节）
- `main.c` 实体键 KEY0/KEY2 与触屏按钮切歌时，改发 `'S' + nxt`
- `host_cdc_sender.py`：
  - `KeyState` 支持 `'S'+idx`；**`'B'` 从「重播当前曲」修正成「上一首」**（原来和板上 KEY2 语义不一致）
  - `stream_playlist` 从 `for enumerate` 重构成 `while + 显式索引`，才能跳到任意曲目
- `DesktopPlayer/core_player.py` 新增 `_cmd_loop()` 命令读线程，收到 `'S'` 调 `play_index()`

> 前提是两边播放列表一致：设备内置 6 个槽位，桌面软件启动会预置 `Tools/plNN.wav` 这 6 首。
> 用户额外导入超过 6 首时，设备发来的 idx 映射到桌面列表前 6 首；第 7 首以后请从桌面软件点选。

## 同步链路（改完后）

```
桌面软件 / host_cdc_sender.py
  ├─ select_slot(idx)      -> 设备置 pending（切歌词/封面）
  ├─ 控制帧 SONG/LRC/POS   -> 设备设歌词时间轴基准 = base_ms/speed
  └─ PCM 按 176400 B/s 发送 -> 设备每收 1 字节累加歌词时钟
                              桌面进度条也用同一份字节数计算
∴ 歌词 = 声音 = 进度条，三者同源
```

## 验证

```bat
py Tools\verify_sync.py
```

离线校验 18 项：固件 T_POS/SetPosition/2 字节上行、桌面 POS 帧格式与 4 字节 LE 值、
POS 在 LRC_END 之后、KeyState 解析 `'S'+idx`/`'B'`/`'N'`、播放循环显式索引、桌面命令读线程、
基准按倍速缩放。**全部通过**，不占用真串口。

真机验收（需重烧固件）：

1. 播放第 1 首 → 按 KEY0 → 屏上跳第 2 首 **且喇叭真的换成第 2 首**
2. 桌面软件拖动进度条到 01:30 → 屏上歌词应正好落在 01:30 那一句
3. 切到 1.5x → 歌词与声音仍对齐（LRC 时间戳和 POS 基准都已缩放）
4. 暂停 → 歌词高亮停住不动，继续后接着走
