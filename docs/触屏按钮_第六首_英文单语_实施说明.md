# 触屏按钮 + 第 6 首「忘不掉的你」+ 英文歌去中文 实施说明

日期：2026-11-14 12:2x　固件：`Output/atk_f407.hex`（0 Error 0 Warning）

## 1. 触屏播放/暂停（新增模块）

屏是 **XPT2046 电阻触摸**（ATK-MD0430 V1.7 原理图确认），走位操作 SPI，不占 FSMC。

| 信号 | 引脚 | 方向 |
|---|---|---|
| T_PEN | PB1 | 输入（按下为低） |
| T_CS | PC13 | 输出 |
| T_MISO | PB2 | 输入 |
| T_MOSI | PF11 | 输出 |
| T_SCK | PB0 | 输出 |

这 5 个脚在本工程原本全空闲（FSMC 屏占 PE7-15/PD0..15/PF12/PG12/PB15；
USB 占 PA11/12；I2S 占 PB12/13/PC12?/PC3/PC6；I2C 占 PB8/9），**没有冲突**。

代码：`User/Hardware/TOUCH/tp.c`（读 12bit ADC、20ms 去抖、坐标线性映射到 800×480）
工程：`Tools/patch_add_touch.py` 新建 `User/Hardware/TOUCH` 组 + IncludePath（幂等）。

### 界面上的三个按钮

放在左栏下方空出来的 90px（y=396..471），每个 76×76：

```
⏮ 上一首(x=4)   ⏸/▶ 播放暂停(x=88)   ⏭ 下一首(x=172)
```

- 播放中显示 ⏸，暂停显示 ▶（`draw_btn_play()` 单独重画，不刷整屏）
- 按下有 50ms 高亮反馈（`lcd_ui_btn_flash()`）
- 命中判定 `lcd_ui_hit(x,y)` → 0/1/2/3；主循环 350ms 内不重复触发

### 按钮到底控制什么

**板子不存音频，真正的暂停必须由电脑执行**。所以按钮只做两件事：

1. 屏幕上的曲目/歌词/时间轴切换（本地）
2. 通过 CDC **IN** 端点给电脑发 1 字节：`P` 暂停 / `R` 继续 / `N` 下一首 / `B` 重播

所以电脑端必须带 `--keys` 跑脚本，否则按键只在屏上生效、声音不跟着动。

## 3. 英文歌去掉中文 + 长句折行（治「马赛克」）

### 3.1 去中文

`Tools/lyrics/pl05_single.lrc`：从 `pl05.lrc` 里删掉 67 行含汉字的译文，
只留 67 句英文。生成 `lrc_data.h` 时用它代替 `pl05.lrc`。

### 3.2 为什么还要折行

40px 字模里 **汉字宽 40、ASCII 宽 16**，歌词区可用宽度 = `LYR_LIMIT - LYR_X` = 796-276 = **520px**。
一句英文平均 35~52 字符 → 只有 25/67 行放得下，其余会退回 32px（16px 字模 2× 放大）= 用户说的马赛克。

### 3.3 改法：单语长句折成两行，两行都保持 40px 原生

`lcd_ui.c` 新增 `LRC_BR = '\x02'` 折行符：

- `wrap_40()` 在 `parse_lrc()` 里就地插符：在**最后一个还能放下的空格**处折；没空格（长中文句）就硬切
- `draw_text40()` 遇到 `LRC_BR` 停止；`draw_block()` 发现 `LRC_BR` 就把后半段画在 `y+44`
- `blk_font()` 见到 `LRC_BR` 直接返回 40（不再降档）；`blk_step()` 折行块步距 92（有译文 108）
- 双语块（含 `\x01`）不动，仍按原逻辑

## 7. 排查

| 现象 | 原因 |
|---|---|
| 点屏幕没反应 | 触摸排线没插好 / 屏不是 XPT2046；串口看 `[TP]` 是否打印 |
| 点左右变成了上下 | `tp.c` 的 `TP_SWAP_XY` 改成 0 |
| 左右反了 | `TP_INV_X` 0↔1；上下反了改 `TP_INV_Y` |
| 只有屏幕变、声音不变 | 电脑端没带 `--keys` |
| 英文又变小了 | 那行字符不在 40px 字库里 → 重跑 `py Tools/gen_big_font.py` |
