## 1. 唱的那句放到歌词区正中间

`lcd_ui.c draw_lyrics()` 原来用「固定第 3 格」（`first = anchor - 2`），当前句总靠上。改成：

```c
ytop = LYR_Y0 + (area_h - blk_step(anchor)) / 2;   /* 当前句垂直居中 */
/* 上方：从当前句往上回填唱过的句子，超出上边界停 */
/* 中间：当前句（高亮 + 彩虹变色） */
/* 下方：依次排没唱的句子，超出下边界停 */
```

歌词区是 `y=6..474`（468px 高），当前句中心约在 y=240，即屏幕正中。

## 2. 不要黑色底挡住封面 —— 找到两个真原因

### 原因 A（主因，是真 bug）：变色动效每 110ms 刷黑条时刷到了左栏

```c
/* 改前：还是老版「上图片下歌词」时代的整屏宽 */
lcd_fill(0, s_act_y, UI_W - 1u, s_act_y + s_act_h - 1, UI_COL_BG);
/* 改后：只清右栏歌词区 */
lcd_fill(LYR_MARK_X - 4u, s_act_y, UI_W - 1u, ... , UI_COL_BG);
```

改成「左 1/3 图 + 右 2/3 歌词」后这行没跟着改，于是**播放时每 110ms 用一条黑横带把左栏封面/歌名擦一遍**。照片里那种黑色挡封面，主要就是它。

### 原因 B：背景板生成时被压暗了 45%

`gen_cover.py` 默认 `--dim 0.50`，再做右侧渐隐到近黑 —— 那是给旧版「右半屏放文字」设计的。
现在左栏只有 256px 宽，却仍在用被压暗的底图，看起来就是一整块灰黑。

修法：
- `add_default_cover.py --dim 1.0` 重新生成 `s_bgD`（只模糊、不压暗），已重新编译进固件；
- `bg_px()` 里的运行时遮罩**整段删除**，封面完整亮出；
- 文字改用 **局部磨砂底 + 1px 深色描边**（`shade_rect` / `draw_text_halo`）：
  只把「文字那一小块」的背景压到 43% 并保留封面纹理，再画白字。
  不是整块黑底，封面主体完全可见。

## 4. 触屏：我到底做没做？为什么按了没反应？

### 老实说

**代码做了，但从来没有在真机上验证过触摸能工作。**

已经做的：
- `User/Hardware/TOUCH/tp.c`（147 行）：XPT2046 位操作 SPI、12bit ADC、去抖、坐标映射
- 已加进 Keil 工程并编译通过（`compiling tp.c` 出现在构建日志里）
- `main.c` 里 `tp_init()` + 每 10ms `tp_scan()` + 命中判定 + 发暂停/切歌命令
- 屏上三个按钮画出来了 —— **你照片里那三个 ⏮ ⏸ ⏭ 就是它**，说明你烧的固件确实带这套代码

没做的：
- **我没有碰过板子、没有量过触摸引脚、没有验证过 PEN 电平和 ADC 读数**
- 5 个引脚（T_PEN=PB1 / T_CS=PC13 / T_MISO=PB2 / T_MOSI=PF11 / T_SCK=PB0）是**从原理图文字推出来的**，不是实测
- 校准常数 `TP_RAW_MIN/MAX`、`TP_SWAP_XY`、`TP_INV_X/Y` 是**猜的**

所以「按了没反应」并不意外：按钮画出来了，不等于触摸信号接进了 MCU。我不能说它已经能用。

### 这一版加了可判定的诊断（烧录后看串口，115200）

开机：
```
[7] TP PEN : 空闲电平=1 (1=高/未按, 0=低)  按屏幕会打印 [TP] x= y=
```

按一下屏幕：
```
[TP] x=120 y=430 raw=1830,2240
```

每 3 秒：
```
      TP: pen=12 ok=8 bad=4
```

| 现象 | 结论 | 下一步 |
|---|---|---|
| `pen=0`，按屏幕也没变化 | PEN 引脚没接 / 有效电平反了 / 这块屏不是 XPT2046 | 把空闲电平那行发我，改 `tp.c` 的极性或引脚 |
| `pen>0` 但 `ok=0` / `bad>0` | PEN 有反应，SPI 读不到数据 → MISO/MOSI/SCK/CS 引脚不对或时序问题 | 把 `raw` 发我 |
| `pen>0, ok>0` 有 `[TP] x= y=` 但仍不动作 | 驱动是通的，只是坐标校准偏了 | 已把热区放宽（左栏 y≥380 按 x 三等分），还不行就把 `x/y` 发我改校准宏 |
| 完全没有任何 `[TP]` 打印 | 烧的不是这一版固件 | 重新 F8 烧录 |

**请烧录后按一下屏幕，把串口这几行发我**，我就能确定是哪一层断了，再改引脚/极性/校准。

### 顺带做的鲁棒化

- `lcd_ui_hit()`：原来只认三个 76×76 小方框，改成**左栏下半段按 x 三等分**（y≥380 即响应），校准有点偏差也能点中；右栏歌词不响应。
- `tp_stats()`：PEN 检测次数 / 成功次数 / 无效次数，3 秒打印一次。
- `tp_pen_level()`：开机自检 PEN 空闲电平。
